# Scratch Game Player v2.20

スマートフォン向けのScratchゲームプレイヤーです。TurboWarp Scaffoldingを利用し、Scratchの共有URLまたはプロジェクトIDからゲームを読み込みます。

## 起動方法

このフォルダーでローカルHTTPサーバーを起動します。

```bash
python -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。

## 操作

- 画面上の十字キー・ABXYボタン：Scratchへのキー入力
- START：Scratchのグリーンフラッグ
- STOP：Scratchの全停止
- 右上の歯車：設定メニュー
- 設定メニュー：Scratchリンク読み込み、本体カラー・デザイン、フルスクリーン、Scratch公開ページへのリンク（作品評価）、作品の使い方・メモとクレジット
- 開発者モード：SB3を選択し、ゲーム名・説明を設定して単独HTMLを生成
- QRコード：開いているプレイヤーのURLに `?project=作品ID` を付けたQRコードを生成し、PNGで保存（Scratch作品を読み込んでいる場合のみ。SB3プレビュー中は生成不可）

Scratchゲームの読み込みが正常に完了した場合だけ、設定メニューが自動で閉じます。失敗した場合はメニューを開いたままエラーを表示します。Scratch作品を読み込んだ場合は、設定メニューに「Scratchで作品を評価する」リンクと、作品ページの「使い方」「メモとクレジット」が表示されます。作品情報の取得に失敗してもゲームの読み込みには影響しません。SB3ファイルのプレビュー中はScratch固有の情報を非表示にします。

## レイアウト

- 縦画面：縦長の携帯ゲーム機風。上部に画面、下部に十字キーとABXY、その下にSTART/STOP。
- 横画面：横長の携帯ゲーム機風。左に十字キー、中央に画面、右にABXYとSTART/STOP。

## 十字キーの立体表現（v2.1）

- 開発者モードの「十字キーの変形」で、パース変形あり／なしを比較できます。
- 上面・側面・下面を独立したレイヤーに分け、側面レイヤーが上面と下面をつなぐ壁として見えるようにしました。
- 押し込んだ方向へ上面を移動・傾斜させ、反対側の側面を広く露出させます。
- 押し込んだ方向の反対側から、側面と上面にソフトライト／ハイライトを追加しました。
- 手前（下）方向への押し込みでは、上面の前後傾斜方向を修正し、側面の露出とハイライト位置が変わるようにしています。
- 変形なしでも上面の移動による側面の厚み変化と照明は維持します。
- 十字キーの入力判定・Pointer Events処理は変更していません。

## CSSの編集

`css/style.css` の先頭から、用途別にコメントを付けています。

- `DESIGN TOKENS`：色、角丸、影などの共通値
- `CONSOLE COLOR PRESETS`：本体カラー・ボタン・画面フレームの着せ替え
- `SETTINGS`：歯車と設定パネル
- `SHARED CONSOLE PARTS`：ゲーム画面・ボタンの基本形状
- `START / STOP`：START/STOPボタンのサイズと色
- `LANDSCAPE`：横画面レイアウト
- `PORTRAIT`：縦画面レイアウト
- 末尾のメディアクエリ：小さい画面でのサイズ調整

まずは `DESIGN TOKENS` のCSS変数を変更すると、全体の雰囲気をまとめて調整しやすくなっています。

## GitHub Pages

リポジトリのルートに `index.html`、`css/`、`js/` を配置し、Settings → Pages → Deploy from a branch → `main` / `root` を選択して保存します。

## 注意

Scaffoldingは `3.14.0` に固定しています。プロジェクトモニターの掃除にScaffolding内部プロパティを利用しているため、バージョンを変更する場合は動作確認が必要です。


## 開発者モード（v0.5）

1. 右上の設定を開き、「開発者モード」を展開します。
2. `.sb3` ファイルを選択し、ゲーム名・説明を入力します。
3. 必要なら「SB3をプレイヤーで確認」で現在のプレイヤー上に読み込み、操作を確認します。
4. 「専用HTMLを生成」を押すと、SB3データを内包したHTMLがダウンロードされます。
5. 生成したHTMLをGitHub Pages等で公開します。
6. 専用HTMLの公開URLは、QRコード作成サービスなどでQR化してください（開発者モードの「このゲームのQRコードを生成」は、読み込み中のScratch作品をこのプレイヤーで開くためのQRコードです）。

生成HTMLはTurboWarp Scaffolding 3.14.0をCDNから読み込みます。そのため、プレイ時はインターネット接続が必要です。SB3データはHTML内に含まれますが、実行エンジンは外部配信です。公開URLを知る人はゲームを遊べるほか、HTMLからSB3データを取り出せる可能性があります。機密データの配布には使用しないでください。

QRコード生成にはqrcodejs 1.0.0をCDNから読み込みます。

## D-pad素材

`assets/dpad/` に以下の9種類のSVGがあります。単独HTML書き出し時は、これらをdata URIとしてCSSに埋め込みます。

- `state-neutral.svg`
- `state-up.svg` / `state-down.svg`
- `state-left.svg` / `state-right.svg`
- `state-up-left.svg` / `state-up-right.svg`
